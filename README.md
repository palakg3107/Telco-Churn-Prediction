# Telco-Churn-Prediction
# Telco Customer Churn Prediction System

# Project Overview

This project develops an AI-based customer churn prediction system for e& (formerly Etisalat). The objective is to identify customers who are likely to leave the company so that proactive retention strategies can be implemented.

# Dataset

The project uses the Telco Customer Churn dataset, containing customer demographics, service subscriptions, billing information, and churn labels.

# Machine Learning Models

Three classification models were implemented:

* Logistic Regression
* Random Forest
* XGBoost

# Model Performance

| Model               | Accuracy |
| ------------------- | -------- |
| Logistic Regression | 73%      |
| Random Forest       | 78%      |
| XGBoost             | 77%      |
